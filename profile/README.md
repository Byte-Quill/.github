## About Us

**Byte Quill** is a GitHub organization created by a dedicated group of friends pursuing a **[Bachelor of Computer Science in Network Technology & Cyber Security (Hons)](https://licnepal.edu.np/bcs-csnt)** at **[Lincoln International College](https://licnepal.edu.np/)**.

We built this collaborative space to **explore, learn, and practice software development together** — focusing on real-world projects, best practices, and continuous growth.
